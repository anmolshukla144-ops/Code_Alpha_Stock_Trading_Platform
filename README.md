CodeAlpha Internship - Task 2

Stock Trading Platform

Language: Java

Concepts: Object-Oriented Programming (OOP), File Handling, Collections

Features

- Simulated stock market data
- Buy and sell stocks
- Portfolio management
- Profit and loss calculation
- Transaction history
- Account balance summary
- Save and load data using file handling

How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Run "javac Main.java".
4. Run "java Main".

Note: This is an educational simulation. Stock prices are simulated and are not live market prices.
